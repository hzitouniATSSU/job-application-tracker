# Job Application Tracker

A full-stack web application for organizing and analyzing a job search.

Users will be able to track job applications, interview stages, company
contacts, notes, resume versions, and job-search statistics from one dashboard.

## Planned Technology Stack

### Frontend

- React
- TypeScript
- Vite
- React Router
- TanStack Query

### Backend

- Node.js
- Express
- TypeScript
- PostgreSQL
- Prisma

### Development and Deployment

- Git and GitHub
- Docker
- Automated testing

## Planned Features

- User registration and login
- Create, view, update, and delete job applications
- Track application and interview stages
- Store notes about each application
- Store recruiter and company contacts
- Record which resume version was used
- Search and filter applications
- Display job-search analytics
- Run the complete project with Docker

## Project Status

The project is currently in the planning and initial setup stage.
