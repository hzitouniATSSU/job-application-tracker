# Project Overview

## Problem

Job seekers frequently manage applications using spreadsheets, notes,
browser bookmarks, emails, and calendars. This makes it difficult to see
the complete status of a job search.

## Proposed Solution

The Job Application Tracker will provide one place where a user can record
applications, monitor interview progress, save company contacts, maintain
notes, associate resume versions, and review job-search analytics.

## Target User

The initial target user is an individual actively applying for jobs and
managing multiple applications.

## Core User Journey

1. The user creates an account.
2. The user signs in.
3. The user adds a job application.
4. The user updates the application's stage as it progresses.
5. The user adds notes and company contacts.
6. The user records which resume version was submitted.
7. The user reviews activity and conversion metrics on the dashboard.

## Minimum Viable Product

The first complete version will include:

- Authentication
- Application CRUD operations
- Application stages
- Notes
- Company contacts
- Resume version records
- Search and filtering
- Dashboard analytics
- Docker configuration

## Features Not Included in the First Version

The first version will not initially include:

- Email synchronization
- Calendar synchronization
- Artificial intelligence features
- Browser extensions
- A native mobile application
- Multi-user teams
